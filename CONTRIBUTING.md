# Contributing to fhir-converter-liquid

Thank you for considering a contribution! We welcome bug reports, feature requests, and pull requests.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Install dependencies: `npm ci`
4. Run tests: `npm test`

## Development

This project converts HL7v2 messages to FHIR R4 using [Liquid templates](https://shopify.github.io/liquid/).

### Requirements

- Node.js 18 or later
- npm

### Running Tests

```bash
npm test
```

### Linting

```bash
npm run eslint
```

## Pull Requests

1. Create a feature branch from `main`
2. Make your changes
3. Ensure tests pass and linting is clean
4. Submit a pull request

## Code of Conduct

Be respectful and inclusive.
